# My Quickshell Config

Currently WIP, only contains basic features like bar and notifications

## Features

- Bar: Contains basic things like Window Title, Workspaces, Systray, Clock, and Widgets.
- Notifications: Simple Notification Popup with pictures/app icons, and Notification Center.
